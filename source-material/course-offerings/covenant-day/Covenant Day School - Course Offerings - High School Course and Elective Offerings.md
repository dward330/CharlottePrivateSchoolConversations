# Covenant Day School — Course Offerings — High School Course and Elective Offerings

> **Provenance:** Transcribed by Claude Code on 2026-08-17 from the school's own
> `/academics/high-school` academics page. The curriculum tiles on that page are Finalsite
> "post" popups: the tile text is NOT in the page HTML — it is fetched on click
> from `/fs/elements/<element_id>?is_popup=true&post_id=<post_id>&show_post=true`.
> A plain `curl` of the academics page therefore returns ZERO course text, which
> is how an earlier pass concluded (wrongly) that this division publishes no
> curriculum. Each section below is the verbatim body of one tile's popup.

### Sources

- Division page: https://www.covenantday.org/academics/high-school
- Popup element id: `40349` — one `post_id` per tile, listed with each section below.
- Retrieval (reproducible):
  `curl -sL "https://www.covenantday.org/fs/elements/40349?is_popup=true&post_id=<POST_ID>&show_post=true"`
