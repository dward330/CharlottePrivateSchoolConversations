# All Schools - Sports - Wells Fargo Cup School Homepages

## Method

Retrieved 2026-11-02 for the school-name links on the Wells Fargo Cup table. Each URL was fetched with curl using a browser user agent. It answered HTTP 200, and the page title names the school. Roster schools link to their own page in the app, so only schools off the roster are listed. The URLs live in `CUP_HOMEPAGES` in `src/data/wellsFargoCup.ts`.

Christ School, Rabun Gap and Saint Mary's match the URLs already held in `src/data/highSchools.ts`.

Wake Christian and Wesleyan Christian do not use the domains older directories list. `www.wakechristian.org` and `www.wesleyan-nc.org` did not answer. The two URLs below came from a web search and were then confirmed by fetching them. `www.wakechristianacademy.com` redirects to the root domain listed here.
