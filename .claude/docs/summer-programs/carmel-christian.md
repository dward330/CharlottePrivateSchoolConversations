## Registration

3 steps via the Summer Adventures Registration Website (Jackrabbit portal): register/select
camps → pay registration fee + camps → access via portal. Deadline 1 week prior to camp
start unless filled. Director Debbie Yates; Asst Director Jen Schultz; Extended Day Admin
Ingrid Hoover; (704) 849-9723.
