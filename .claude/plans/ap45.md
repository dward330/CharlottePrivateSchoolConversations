# Add an "AP scoring 4 or 5" metric to College Support

## Goal

The user asked for the share of AP exams scoring a 4 or 5 to appear in two places. The
first is a new row on Compare (College Support). The second is a stat tile in the College
Support header on each school page, next to the existing "AP scoring 3+" tile. Schools
that do not publish the figure show nothing. The work is done when:
- both surfaces show the five filled schools in English;
- every value traces to a committed source file;
- `npm run build` is green after Phase 2.

**This is a direct UX request from the user (2026-11-05), so it is already approved.** It is
a new metric key and a new Compare row. Nothing beyond what is described here is approved.

## Context

### One entry drives both surfaces

The College Support header strip and the Compare rows read the **same** list,
`VALUE_METRICS` in [`src/data/metricValues.ts`](../../src/data/metricValues.ts):
- **The header strip.** [`src/pages/SchoolDetail.tsx`](../../src/pages/SchoolDetail.tsx)
  ~831 builds the stat strip from `valueMetricsForTopic(t.slug, lang)`, filtered to
  `!vm.compareOnly && vm.values[slug] != null`. Each tile renders `values[slug]`. For
  `college-support` only, it also renders `subs[slug]`, plus `label` (~1109–1133).
- **Compare.** [`src/pages/Compare.tsx`](../../src/pages/Compare.tsx) renders one row per
  entry, with `vm.label`, `vm.note` and per-cell `quals` (~551–564). Tile order and row order
  are both array order.

So **one new `ValueMetric` entry, inserted directly after `ap-performance`** (metricValues.ts
~292–340), gives both a Compare row under "AP scoring 3+" and a header tile right after the
3+ tile. A school with a `null` value gets no tile and an empty Compare cell, which is the
existing behaviour for Davidson Day and Hickory Grove on the 3+ row.
- Do **not** set `compareOnly`.
- No component or CSS change is needed. `.stat-strip` is an `auto-fit` grid
  (`src/index.css` ~1255), so one more tile wraps cleanly.

### Sequencing with `pdprofile`

`pdprofile` (Not implemented) moves Providence Day's 3+ cell from `94%` `(2025)` to `93%`
`(2026)`. Its 2025 figure for 4-or-5 was 77%. **Implement `ap45` after `pdprofile` has
merged**, so that PD's two AP cells share a year. If `pdprofile` has not merged when this
runs:
- ship PD as `77%` `(2025)`, with the qual "77% of AP exams scored 4 or 5 in May 2025 (1,213
  exams).";
- note in the PR that `pdprofile` must then also move this cell to 76% `(2026)`;
- add that line to `pdprofile.md`'s D6.

### Coverage floor

`npm run coverage:floor` counts every Compare row. This row raises the total from 36 to 37,
and Davidson Day, the floor school, is null on it. Leave the row **counted**, as the 3+ row
is: whether a school publishes it is the school's choice, not structural like the Cup or
Global Exposure exclusions. The script derives the new floor itself. Do not edit any
transcribed count.

## Decisions

- **D1 — Key, label and note.**
  - key `'ap-top-scores'`.
  - label `'AP scoring 4 or 5'`, parallel to `'AP scoring 3+'`.
  - note: `'Share of AP exams scoring 4 or 5, most recent reported year. Only five schools
    publish it, or a per-subject table it can be counted from.'`
- **D2 — Quals: one `kind: 'scope'` qual per filled cell**, in the 3+ row's style:
  - Catholic: "76% of 1,184 AP exams scored 4 or 5 in 2026. AP exams are mandatory in every
    AP course at CCHS."
  - Covenant Day: "78% of AP exams scored 4 or 5 in 2026 (401 exams; every AP student must sit
    the exam)."
  - Country Day: "74% of AP exams scored 4 or 5 overall in 2025 (530 exams)."
  - Latin: "75% of 833 AP exams scored 4 or 5 in 2026 — 625 exams, counted from the
    per-subject results table in the school's profile, which prints no 4-or-5 share itself."
  - Providence Day: "76% of AP exams scored 4 or 5 in May 2026, across 1,282 exams; every AP
    student must sit the exam."
  - Each qual ends with: "A 4 or 5 is the level most selective colleges look for in credit
    and placement."
  - Latin's qual says what the school publishes (a table) and how the figure follows from it.
    That is parent-facing and not research bookkeeping, so it stays a `scope` qual.
- **D3 — Code comments** on each value record the exact counts and file. For Latin, the
  comment says `// COUNTED from the profile's per-subject table: (366+259)/833 = 75.03%`.
- **D4 — No card changes.** The College Support cards already state these figures where they
  have them (Catholic, Covenant Day and CCD transcript stats). The tile repeats them above the
  card, as the 3+ tile already does. That is accepted precedent, so this row is not
  `compareOnly`.
- **D5 — No chrome keys.** The row label, note and quals are prose in the `metric-values`
  overlay topic, the same as the 3+ row (`src/data/overlays/metric-values.<lang>.json`).
  `src/locales/*.json` is untouched.
